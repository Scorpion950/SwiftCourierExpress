SwiftCourier Express - Project Information
=================================================================

Project Description:
This file contains the technical reference for SwiftCourier Express, a Python-based courier management system developed with Flask. The application is designed to manage parcel bookings, customer records, shipment tracking, billing, reports, and admin settings for a courier business.

Project Name:
SwiftCourier Express Courier Management System

Project Type:
Full-stack web application built with Python + Flask for admin management and parcel tracking.

Technology Stack:
1. Backend: Python 3.11+
2. Web Framework: Flask 3.0.3
3. ORM: Flask-SQLAlchemy 3.1.1
4. Authentication: Flask-Login 0.6.3
5. Forms + CSRF: Flask-WTF 1.2.1
6. Database Migrations: Flask-Migrate 4.0.7
7. Database: PostgreSQL / Neon PostgreSQL
Beginner Setup (Windows PowerShell):

Prerequisites:
- Install Python 3.11 or later and enable the option to add Python to PATH.
- Install Git if you are downloading the source from GitHub.
- Create a PostgreSQL database, for example a Neon PostgreSQL project, and keep its connection string private.

Where the .env file goes:
- The actual .env file is not included in GitHub because it contains private credentials.
- Create it in the top-level project folder, beside README.md, run.py, and requirements.txt.
- The committed .env.example file is a safe template with placeholder values.
- From PowerShell in the top-level project folder, create and open your local file:
  Copy-Item .env.example .env
  notepad .env
- Replace the example values, save the file, and close Notepad. The root .gitignore excludes .env from Git.
- Never share or commit a real database password, secret key, or admin password.

Values to put in .env:
DATABASE_URL=postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require
SECRET_KEY=replace-with-a-long-random-secret
ADMIN_EMAIL=your-admin-email@example.com
ADMIN_PASSWORD=choose-a-strong-password

Install and run the project:
1. Open PowerShell in the top-level project folder (the folder containing README.md).
2. Create a Python virtual environment:
   py -3.11 -m venv .venv
3. Install every package listed in requirements.txt:
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
4. Create and edit .env as described above. Use the connection string provided by your PostgreSQL host.
5. Create the database tables and configured admin/settings records:
   .\.venv\Scripts\python.exe seed.py
6. Start the development server:
   .\.venv\Scripts\python.exe run.py
7. Open the app in your browser:
   http://127.0.0.1:5000
8. Stop the server by pressing Ctrl+C in PowerShell.

Useful Commands (from the top-level project folder):
- Install packages: .\.venv\Scripts\python.exe -m pip install -r requirements.txt
- Seed the database: .\.venv\Scripts\python.exe seed.py
- Start the app: .\.venv\Scripts\python.exe run.py
- Run automated tests: .\.venv\Scripts\python.exe -m pytest -q
- Start in production on Linux: gunicorn wsgi:app

Admin Login:
Use the login identifier and password configured with ADMIN_EMAIL and ADMIN_PASSWORD in your private .env file. The identifier can be username-style. Set a strong password before running seed.py. There is no shared default password to use or publish.

Important Notes:
- requirements.txt lists the required Python packages; pip installs them into .venv.
- PostgreSQL/Neon URLs should include sslmode=require.
- The app uses Flask's application factory. run.py is the local entry point and wsgi.py is the production entry point.
- The mobile hamburger menu is in app/templates/layout.html and app/static/js/app.js; route and template paths remain under the app package.
- Do not upload .env, .venv, or local database files to GitHub.

Developer Notes:
